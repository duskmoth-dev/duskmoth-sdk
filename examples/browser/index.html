Read availability with Duskmoth SDK

This page and its simulated API share one localhost origin. No external API, wallet, credentials, pass spending, storage, or blockchain activity is used.

Choose a scenario, then read its local fixtures.

    What this demonstrates

    Read-only health, configuration, and pass availability. Even an available flag does not prove that a payment will succeed. A missing field means unknown, not ready.

    Same origin, not a CORS bypass

    No CORS permission is needed here because all requests stay on this local server. A real cross-origin integration still needs the API operator's explicit CORS policy or your own same-origin backend.
